Penggabung File Excel & CSV

Gabungkan banyak file Excel atau CSV menjadi satu tabel. Kolom dengan nama yang sama disatukan otomatis meskipun urutannya berbeda.

1Pilih file

    2Pengaturan

    Ubah jika file punya judul laporan di atas tabel, misalnya judul kolom ada di baris 3.

    3Hasil gabungan

    Pilih minimal dua file untuk mulai menggabungkan.

    ☕ Tool ini menghemat waktumu? Dukung pengembangannya lewat traktir kopi agar tetap gratis.

    Cara menggabungkan banyak file Excel

    1. Pilih file. Klik kotak di atas atau seret beberapa file Excel/CSV sekaligus.
    2. Atur penggabungan. Pilih apakah hanya sheet pertama atau semua sheet yang digabung, dan bagaimana kolom dicocokkan.
    3. Periksa pratinjau. Lihat 50 baris pertama hasil gabungan dan daftar kolomnya.
    4. Unduh hasil. Simpan sebagai Excel (.xlsx) dengan header berwarna dan filter otomatis, atau sebagai CSV.

    Cocokkan berdasarkan nama atau urutan?

    Berdasarkan nama cocok untuk laporan dari cabang atau periode berbeda yang urutan kolomnya tidak selalu sama. Kolom yang hanya ada di sebagian file tetap disertakan, dan sel di file lain dibiarkan kosong. Berdasarkan urutan cocok jika semua file memakai template yang persis sama tetapi nama judulnya kadang berbeda.

    Contoh penggunaan di HR

    • Menggabungkan rekap absensi dari beberapa departemen atau lokasi menjadi satu.
    • Menyatukan data karyawan dari beberapa anak perusahaan.
    • Menggabungkan laporan bulanan Januari sampai Desember menjadi data setahun.
    Privasi terjamin: file dibaca dan diproses sepenuhnya di browser kamu. Tidak ada data karyawan yang dikirim ke server mana pun, sehingga aman untuk data sensitif seperti gaji atau NIK.

    Pertanyaan yang sering diajukan

    Apakah ada batas jumlah atau ukuran file?

    Tidak ada batas khusus. Kemampuan bergantung pada memori perangkat. Ratusan ribu baris umumnya masih bisa diproses dengan lancar di komputer.

    Bagaimana jika file punya judul laporan di atas tabel?

    Atur "Judul kolom ada di baris ke-" sesuai posisi judul kolom. Baris di atasnya akan dilewati di semua file.

    Apakah format tanggal tetap terbaca?

    Ya. Tanggal di file Excel tetap disimpan sebagai tanggal di file hasil dengan format dd/mm/yyyy.

    Apakah rumus Excel ikut terbawa?

    Yang digabungkan adalah nilai hasil rumus, bukan rumusnya. Ini membuat hasil gabungan tetap benar walaupun file sumbernya tidak ikut disertakan.

    Baris kosong ikut digabung?

    Tidak. Baris yang seluruh selnya kosong dilewati secara otomatis.
