Penghapus Data Duplikat

Temukan dan hapus baris ganda di file Excel atau CSV berdasarkan kolom pilihan, misalnya NIK atau nama. Baris duplikat tidak dibuang begitu saja, melainkan dipisahkan supaya bisa kamu periksa.

Cara menghapus data duplikat di Excel

  1. Pilih file Excel atau CSV yang ingin dibersihkan, lalu pilih sheet-nya.
  2. Tentukan kolom kunci. Baris dianggap duplikat jika semua kolom yang dipilih bernilai sama.
  3. Periksa hasilnya di tab "Data bersih" dan "Duplikat".
  4. Unduh file Excel berisi dua sheet: Data Bersih dan Duplikat, lengkap dengan nomor baris asli.

Memilih kolom kunci yang tepat

  • Data karyawan: pilih NIK atau nomor induk karyawan, karena nama bisa sama untuk orang yang berbeda.
  • Rekap absensi: pilih NIK dan Tanggal untuk menemukan absensi yang tercatat dua kali di hari yang sama.
  • Data hasil gabungan: pilih semua kolom untuk membuang baris yang benar-benar identik.

Kenapa tidak langsung pakai Remove Duplicates di Excel?

Fitur bawaan Excel langsung menghapus baris tanpa memperlihatkan apa yang dihapus, dan menganggap "Budi" dan "budi " sebagai data berbeda. Tool ini menunjukkan setiap baris duplikat beserta nomor baris aslinya dan baris mana yang disimpan, sehingga kamu bisa memeriksa sebelum memakai datanya.

Privasi terjamin: file dibaca dan diproses sepenuhnya di browser kamu. Data karyawan seperti NIK atau gaji tidak dikirim ke server mana pun.

Pertanyaan yang sering diajukan

Apakah file asli saya berubah?

Tidak. File asli tidak diubah sama sekali. Hasil pembersihan diunduh sebagai file baru.

Apa arti kolom "Duplikat dari baris"?

Kolom itu menunjukkan nomor baris di file asli yang disimpan sebagai data utama. Dengan begitu kamu bisa membandingkan baris duplikat dengan baris yang dipertahankan.

Apakah NIK berawalan 0 tetap aman?

Ya. Isi file CSV dibaca sebagai teks apa adanya, sehingga angka nol di depan tidak hilang.

Bagaimana jika file berisi banyak sheet?

Pilih sheet yang ingin dibersihkan di menu Sheet. Untuk membersihkan data dari banyak sheet atau banyak file sekaligus, gabungkan dulu dengan Penggabung File Excel.
